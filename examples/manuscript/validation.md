The retained directory contained 22,515 regular files totaling 1,684,930,225
bytes. Its gzip-compressed tar archive was 221,399,280 bytes, with SHA-256

These measurements include staged inputs, outputs, logs, diagnostics, and CSV
exports; they exclude the Docker image and external model source checkouts.
The raw archive is retained locally and is regenerated by the full workflow.
It is not a required download or a tracked software artifact.

CSV comparison checks row counts, required columns, categorical identifiers,
and numeric values. The absolute tolerance is `5e-6`, plus `1e-8` times the
value magnitude; volume-error and volume-residual columns allow `1e-4 m3` for
roundoff differences between builds. These are data-comparison tolerances.
The scientific budget and convergence criteria are enforced separately by the
experiment suite. All twelve nonlinear kernel comparisons had zero error.
The intentionally unresolved within-cell redistribution in the spatial
mapping diagnostic is a model limitation, not a failed software test.
